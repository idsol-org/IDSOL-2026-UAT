Submission Materials

Pitch Deck

  • Format: PDF or PowerPoint (PPTX), maximum 30 slides.
  • Content: Problem statement, solution architecture, data science methodology, market analysis, and team credentials.
  • Language: English only.
  • Branding: Must include team name and IDSOL 2026 reference on the title slide.

Project Report

  • Format: PDF, maximum 20 pages (excluding appendices).
  • Structure: Executive summary, technical methodology, dataset description, findings, and conclusions.
  • Citations: APA or IEEE citation format required.
  • Language: English only.
Optional

Prototype / Demo

  • Format: Video demo (MP4, max 5 minutes) or live accessible link.
  • Scope: Demonstrates the core functionality of the proposed solution.
  • Hosting: YouTube (unlisted), Google Drive, or GitHub Pages.
  • Highly recommended for PROD stream projects.
Optional

Appendices

  • Supporting datasets (links to public repositories preferred).
  • Source code repositories (GitHub, GitLab).
  • Additional visualizations, charts, or models.
  • Reference letters from supervisors or mentors.

Evaluation Criteria

INFRA Stream

Innovation 30%
"Does the solution address a novel enterprise-level challenge?"
  • Originality of the proposed infrastructure approach
  • Differentiation from existing solutions
  • Scalability and systemic resilience design
Technical Depth 40%
"Is the DSAI methodology rigorous and well-justified?"
  • Data science pipeline clarity
  • Algorithm and model selection rationale
  • Evaluation metrics and validation approach
Impact 30%
"What real-world difference would this solution make?"
  • Alignment with SDGs
  • Commercial or institutional viability
  • Societal benefit and ethical considerations

PROD Stream

Usability 30%
"How accessible and intuitive is the product?"
  • User experience and interface design
  • Accessibility for the target demographic
  • Ease of adoption
Technical Merit 40%
"Does the DSAI application function correctly and creatively?"
  • Complexity and sophistication of AI/ML components
  • Data utilization and model performance
  • Robustness and reliability
Market Fit 30%
"Is there genuine consumer demand for this product?"
  • Target audience analysis
  • Competitive landscape awareness
  • Monetization or sustainability model
